# 24 · Glossary

| Term | Meaning |
|---|---|
| Accounting stock | Stock as the books see it: moved by bills, invoices, credit notes, adjustments, production |
| Ack No / Ack Date | Acknowledgement number and time returned by the IRP with an IRN |
| AP / AR | Accounts payable (owed to vendors) / accounts receivable (owed by customers) |
| B2B / B2C / B2CL / B2CS | Supplies to registered businesses / to consumers; B2C large (inter-state above the threshold) / B2C small |
| BOM | Bill of materials: components and operations to make an item |
| CDNR / CDNUR | Credit/debit notes to registered / unregistered recipients (GSTR-1) |
| CGST / SGST / IGST | Central, State and Integrated GST |
| COGS | Cost of goods sold |
| Committed stock | Quantity on confirmed sales orders not yet shipped |
| CTC | Cost to company: annual salary including employer contributions |
| Delivery challan | Document for moving goods without a sale (job work, approval, branch transfer) |
| EPF / EPS / EDLI | Employees' Provident Fund / Pension Scheme / Deposit Linked Insurance |
| ESI | Employees' State Insurance |
| e-Way bill (EWB) | Electronic permit for moving goods above the value threshold; Part-A (document), Part-B (vehicle) |
| FIFO | First in, first out costing |
| GRN | Goods receipt note (purchase receive) |
| GSTIN | 15-character GST identification number |
| GSTR-1 / GSTR-3B / GSTR-2B | Outward supply return / summary return with tax payment / auto-drafted ITC statement |
| HSN / SAC | Harmonised System code for goods / Services Accounting Code |
| IRN / IRP | Invoice Reference Number / Invoice Registration Portal |
| ITC | Input tax credit: GST paid on purchases that can offset output GST |
| Landed cost | Freight and similar charges added to the cost of stock |
| LOP | Loss of pay days (unpaid absence) |
| LUT | Letter of undertaking: export without paying IGST |
| MO | Manufacturing order |
| MRP | Material requirements planning |
| Physical stock | Stock actually in the warehouse: moved by receives, shipments, challans, returns, transfers |
| Place of supply (POS) | State whose tax applies; decides intra- vs inter-state |
| PT | Professional tax (state levy on salaries) |
| RCM | Reverse charge mechanism: the buyer pays the GST |
| RFQ | Request for quotation |
| Sales return (RMA) | Return merchandise authorisation for goods coming back from a customer |
| SEZ | Special Economic Zone |
| SLM / WDV | Straight-line / written-down-value depreciation |
| Surrogate bid | A vendor's bid entered by staff on the vendor's behalf |
| TDS | Tax deducted at source |
| UAN | Universal Account Number (EPF) |
| UQC | Unit Quantity Code used in GST returns and e-invoices |
| Void | Cancelled document kept for the number series; has no stock or ledger effect |
| WAC | Weighted average cost |
| YTD | Year to date |
